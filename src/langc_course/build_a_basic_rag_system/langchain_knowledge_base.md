
# LangChain Knowledge Base

## What is LangChain?

LangChain is a framework for developing applications
powered by large language models (LLMs).

It provides tools to connect language models with
external data sources, APIs, databases, and tools.

## What are Vector Stores?

Vector stores are databases designed to store and
search numerical vector representations of data.

They allow applications to retrieve documents based
on semantic similarity.

## What is RAG?

Retrieval-Augmented Generation (RAG) is a technique
that retrieves relevant information from an external
knowledge source before generating an answer.

RAG combines information retrieval with language
model generation.

## What is ChromaDB?

ChromaDB is an open-source vector database used to
store embeddings and perform similarity searches.
